# My Favorite Anime: Jujutsu Kaisen

Welcome to my project repository! Here is a little bit about my favorite anime show.

## About the Show
* **Genre:** Action / Dark Fantasy / Supernatural
* **Setting:** Modern-day Japan (with hidden sorcery society)
* **Main Premise:** A high schooler swallows a cursed talisman and joins a secret organization of jujutsu sorcerers to combat evil curses.

> "I don't know how I'll feel when I die, but I don't want to regret the way I lived." — Yuji Itadori

### Main Characters
1. Yuji Itadori
2. Megumi Fushiguro
3. Nobara Kugisaki
